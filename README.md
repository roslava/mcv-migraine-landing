# Лендинг лечения мигрени

Медицинский центр Власова — страница записи к врачу-неврологу и цефалгологу Дарье Юрьевне.

## Структура

- `index.html` — основная страница лендинга
- `logo.svg` — логотип клиники

Фото врача загружается с внешнего хранилища (Yandex Cloud).
